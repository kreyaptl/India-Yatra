## 📖 Project Overview
**IndiaYatra** is a comprehensive, responsive web application designed to bridge the gap between local commutes and cross-country adventures. It provides a unified platform where users can explore destinations, plan journeys, and calculate fares across six major modes of transport: Bus, Cab, Auto, Metro, Train, and Flight.

![Project Screenshot](ScreenShot.png) 

---

## ✨ Key Features
* 📱 **Fully Responsive UI:** Flawless experience across desktop, tablet, and mobile devices.
* 🧮 **Dynamic Fare Calculator:** Real-time JavaScript engine that estimates travel costs based on distance and vehicle type.
* 🔍 **Interactive Filtering:** Live search functionality to easily find specific transport routes.
* ⭐ **Custom Rating System:** Interactive 5-star feedback UI with animated toast notifications.
* 🔐 **Authentication UI:** Sleek split-screen design for user login and registration with form validation.

---

## 🛠️ Technologies Used
* **Frontend Structure:** HTML5 (Semantic elements, multi-page routing)
* **Styling:** CSS3 (Flexbox, CSS Grid, custom properties/variables, animations)
* **Logic & Interactivity:** Vanilla JavaScript (DOM manipulation, event listeners, dynamic math logic)
* **Icons & Fonts:** FontAwesome 6.5, Google Fonts (Playfair Display, DM Sans, Dancing Script)

---

## 🚀 Website Flow & Architecture
1. **`index.html` (Home):** Hero section with quick-search widgets, live stat counters, and popular destination cards.
2. **`services.html` (Services):** A dynamic grid displaying all transport options with a built-in search filter and demo booking tools.
3. **`calculator.html` (Fare Calc):** The core utility page featuring the algorithmic fare estimator.
4. **`feedback.html` (Feedback):** Client-side review submission with hover-state star ratings and simulated backend success responses.
5. **`auth.html` (Login/Register):** Tab-based authentication interface with client-side input validation.
